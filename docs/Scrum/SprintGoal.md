# Sprint Goal – Mi Formación CTMA

## Objetivo del Sprint

Implementar y validar las funcionalidades principales de Mi Formación CTMA relacionadas con la consulta, organización y seguimiento de las actividades formativas.

## Resultado esperado

Al finalizar el Sprint, el usuario debe poder:

- Consultar las actividades formativas.
- Conocer el progreso de cada actividad.
- Identificar el estado de las actividades.
- Identificar actividades urgentes.
- Conocer la prioridad de las actividades.
- Consultar un resumen general del progreso.
- Buscar actividades por título.
- Validar los datos de las actividades.

## Alcance del Sprint

El Sprint contempla las historias de usuario:

- HU-01 – Consultar actividades formativas.
- HU-02 – Consultar el progreso de una actividad.
- HU-03 – Identificar el estado de una actividad.
- HU-04 – Identificar actividades urgentes.
- HU-05 – Consultar el promedio de progreso.
- HU-06 – Buscar actividades por título.
- HU-07 – Priorizar actividades.
- HU-08 – Consultar resumen de avance.
- HU-09 – Validar datos de una actividad.

## Criterio de éxito

El Sprint se considera exitoso cuando las funcionalidades incluidas están implementadas, las reglas de negocio funcionan correctamente, las pruebas correspondientes pasan y el proyecto compila sin errores.

## Evidencia

La validación del Sprint se realizará mediante:

- Pruebas unitarias.
- Pruebas instrumentadas cuando correspondan.
- Ejecución de la aplicación en el emulador.
- Compilación exitosa del proyecto.
- Commits asociados al trabajo realizado.
