# Definition of Done – Mi Formación CTMA

Una actividad se considera terminada cuando cumple las siguientes condiciones:

- [ ] La funcionalidad está implementada en Kotlin.
- [ ] La funcionalidad está integrada correctamente en la aplicación Android.
- [ ] La interfaz funciona correctamente con Jetpack Compose.
- [ ] Las reglas de negocio están separadas de la interfaz.
- [ ] Las validaciones requeridas están implementadas.
- [ ] Se han considerado los estados y prioridades correspondientes.
- [ ] La funcionalidad ha sido probada.
- [ ] Las pruebas correspondientes pasan correctamente.
- [ ] No existen errores conocidos que impidan utilizar la funcionalidad.
- [ ] La interfaz presenta la información de forma clara.
- [ ] Se han considerado aspectos básicos de accesibilidad.
- [ ] El proyecto compila correctamente.
- [ ] Los cambios han sido revisados.
- [ ] El cambio está guardado mediante un commit en Git.
- [ ] El cambio puede ser relacionado con la historia de usuario o tarea correspondiente.
